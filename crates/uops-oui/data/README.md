# The IEEE MAC-assignment table

`assignments.tsv` is generated by `scripts/oui.sh` from the four public registries IEEE
publishes at <https://standards-oui.ieee.org/>:

| File | Registry | Width |
|---|---|---|
| `oui/oui.csv` | MA-L | 24 bits |
| `oui28/mam.csv` | MA-M | 28 bits |
| `oui36/oui36.csv` | MA-S | 36 bits |
| `cid/cid.csv` | CID | 24 bits, **not unique** |

**Downloaded 2026-09-16.** Regenerate with `bash scripts/oui.sh` and update that date.

Each line is `<assignment hex>\t<registry letter>\t<organisation>`. The hex length says
how wide the assignment is — six characters is 24 bits, seven is 28, nine is 36 — so
there is no separate width column. Entries whose organisation is `Private` or the
registration authority itself are dropped: a vendor column reading "Private" is worse
than an empty one, because it looks like a company of that name.

The postal address each registry carries is dropped too. It is most of their 5.2 MB and
is of no use to an inventory.

## Why this is committed rather than downloaded

A poller in an air-gapped network is the normal case for this product, not the exception,
and a build that reaches the internet is a build that fails behind a proxy. The table is
embedded with `include_str!`, so there is no fetch at build time or at run time and no
file for a deployment to forget to mount.

The cost is that it goes stale: new assignments appear every week, and a device from a
company registered after the date above resolves to nothing rather than to the wrong
answer. Re-running the script is a one-line change to this directory.

## Provenance, and the thing to check before selling this

IEEE publishes these registries openly and they are redistributed widely — Wireshark,
nmap and Debian's `ieee-data` package all ship them. That is the basis on which they are
bundled here.

It is **not** a licence review. IEEE does not attach an SPDX identifier to the files, and
`cargo deny` checks the licences of crates rather than the terms of embedded data, so
nothing in CI is looking at this. Confirm the terms before a commercial release — it is
recorded in STATUS beside the CLA for that reason.
